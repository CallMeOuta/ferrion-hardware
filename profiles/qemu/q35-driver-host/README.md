# QEMU q35 with virtio-gpu on Linux's driver in the driver host

Generated by `python3 scripts/profile.py readme`. Format: `python3 scripts/profile.py schema`.

Opt-in only: select this profile by name in an image config. Hardware matching never suggests it.

Widens access:

- Linux 6.18.64's virtio-gpu driver, DRM core and dma-buf code (104 files, 87,219 lines of C) and the host's shim drive the virtio-gpu PCI function in place of virtio-gpud
- The driver host takes the device's legacy INTx interrupt line, which q35 can share with other devices, where virtio-gpud uses MSI-X
- The driver host holds up to 1 GiB of physically contiguous memory with its physical addresses, which it hands to the device; this machine has no IOMMU
- /etc/pcid.d/virtio-gpud.toml replaces the stock entry, so the root file system's pcid-spawner starts the driver host on 1af4:1050

Start: `make qemu gpu=virtio`.

Requires: KVM; OVMF.
